# Licensing basis for ARGOS Defense 0.2.0

This records why Apache-2.0 was applied. It is an engineering provenance review, **not legal advice or certification**.

## What was inspected (2026-11-20)
- **Source code** (`src/argos/**`): written for ARGOS in Python. The ARTEX reference is Go/TypeScript. No file in `src/` was copied or translated from ARTEX. The design ideas adopted are listed in `docs/INSPIRATION_MAP.md`; each was re-implemented independently.
- **Templates and static assets** (`templates/*.html`, `static/app.css`, `static/app.js`): written for ARGOS; no third-party templates, fonts, icons or images.
- **Detection rules** (`resources/rules/**`): written for ARGOS. Family-7 rules contain short factual references to ARTEX (file paths, line numbers, the session-id pattern `exp<N>-…`, the file name `_ca/mitmproxy-ca-cert.pem`, the binary name `artex`) to describe candidate observations. These are identifiers used to describe the reviewed software, not reproduced program code.
- **Synthetic fixtures/screenshots**: generated by ARGOS code.
- **Dependencies**: used as libraries under their own permissive licenses (see `THIRD_PARTY_NOTICES.md`); none is AGPL/GPL-only. defusedxml (PSFL) and typing_extensions (PSF-2.0) are permissive.
- **Previous handover claim** "no ARTEX code copied" was re-checked by comparing the ARGOS sources against the reference tree. The only shared strings are the short identifiers above.

## Decision
ARGOS Defense is distributed under **Apache-2.0** with the canonical license text (`LICENSE`, SHA-256 `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`, identical to https://www.apache.org/licenses/LICENSE-2.0.txt). The ARTEX checkout (AGPL-3.0) is excluded from the repository and all distributables; a pinned manifest and retrieval script are provided instead.

## Unresolved items
None known for the distributed material. If the project owner prefers a different license, change `LICENSE`, `pyproject.toml` and this file together before the next release.
