## Notes
- **Schema v4:** adds watcher checkpoint identity columns. v0.3.0 checkpoints are marked `legacy`, and a `coverage_semantics` note is added. Migration is transactional after a verified backup (`argos.v3-backup.sqlite3`). See `tests/test_upgrade_v030.py`, which uses a v0.3.0 demo database produced by the v0.3.0 code.
- **Observable behaviour changes:**
  - A coverage declaration without event kinds no longer demonstrates the absence of other event families.
  - LLM tool-call chains across separately imported files need a declared collector id.
  - `backup` fails when evidence is missing (unless `--allow-incomplete`), and `verify-backup` reports database consistency and evidence completeness separately.
  - Only one server can run per data directory.
