## Disagreements with the audit
None of the findings was disproved. Two clarifications:
- F06: as the audit stated, the *working* database had not lost data; only the recovery copy was incomplete. The fix concerns the backup.
- F12: the audit's simulated archives show the gate was incomplete; it does not show that the earlier dry-run packages were corrupt. The v0.2.0 packages were never published.

## Related issues found during remediation
- A test fixture wrote into the packaged default `rule_overrides.yaml`; tests now use a private configuration copy (`tests/conftest.py`) and the packaged file was restored.
- Sigma export: native regex predicates are case-insensitive but Sigma `|re` is case-sensitive; the exporter now emits `|re|i` (found by `tests/test_sigma_semantics.py`).
- Windows: `icacls` prints in the OEM code page; output is now decoded as bytes (CI Windows failure fixed).
