**ARGOS Defense 0.3.0 — experimental detection; real-world accuracy not measured.**

Local, offline defensive investigation of supplied telemetry files (native JSONL/JSON, Splunk JSON/CSV, Sysmon XML, Zeek JSON) with six separate evidence dimensions: threat activity, automation, LLM involvement, framework association, purpose/outcome, and entities. ARGOS does not identify people, groups, nationalities or exact models, and performs no blocking or response.

This release fixes the thirteen findings of an external audit (docs/AUDIT_REMEDIATION.md): LLM involvement is only "directly observed" with an explicit model-tool-call link; failed actions are reported as attempts; observation span is no longer mistaken for collection coverage; redaction covers structured secrets; backups include committed WAL data; data files are owner-private; evidence navigation finds the exact original record; analysis runs are immutable snapshots that can be compared; imports can be reprocessed with corrected options; and the release pipeline enforces a complete, independently verified asset contract.

### Signing
Windows: not Authenticode-signed. macOS: ad-hoc signature only — not Developer ID signed, not notarized (if Gatekeeper blocks the first launch use System Settings → Privacy & Security → Open Anyway). Build-provenance attestation status: see `release-manifest.json`. Checksums provide integrity, not publisher authenticity.

### Upgrading
Start the new version with your existing data directory. The database is migrated to schema v3 in one transaction after a verified backup (`argos.v2-backup.sqlite3`). Earlier analysis runs stay visible and are labelled "legacy (no snapshot)"; re-analyse to create a snapshot. Imported originals are unchanged. Model/tool audit exports now need `tool_call_id` (and `tool_name` on executions) for a direct model-to-execution link; without them, ARGOS reports "possible".

### Evaluation (synthetic only)
Reserved synthetic set (415 units, first inspected once with these rules): benign units with a low-or-higher alert 68/200; detection by scenario 20/20 for most attacks, 19/20 for password spray, 0/20 for source rotation interleaved with the real user's sign-ins (known gap); no incorrect LLM or framework assertions; identical traces with different hidden origins produced identical conclusions (5/5). The same author wrote the rules and generated the data: this is synthetic held-out validation, not real-world accuracy. Details: docs/EVALUATION_PROTOCOL.md.

### Not included / not verified
Binary EVTX (blocked: parser and genuine Sysmon EVTX sample unavailable in the build environment), PCAP, live EDR/SIEM connectors, automatic containment, universal human-vs-LLM classification. Cases above 300,000 events are refused (in-memory analysis). Real Ollama integration, Splunk/Sigma backend execution, genuine vendor exports and desktop editions of Windows/macOS are not verified.
