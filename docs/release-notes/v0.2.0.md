**ARGOS Defense 0.2.0 — first packaged release. Experimental detection; real-world accuracy not measured.**

Local, offline defensive investigation of supplied telemetry files (native JSONL, Splunk JSON/CSV, Sysmon XML, Zeek JSON) with six separate evidence dimensions: threat activity, automation, LLM involvement, framework association, purpose, and entities. ARGOS does not identify people, groups, nationalities or exact models, and performs no blocking or response.

### Signing
Windows: not Authenticode-signed. macOS: ad-hoc signature only — not Developer ID signed, not notarized (use System Settings → Privacy & Security → Open Anyway if Gatekeeper blocks the first launch). No GitHub artifact attestations (unavailable for private repositories outside GitHub Enterprise Cloud). Checksums provide integrity, not publisher authenticity.
